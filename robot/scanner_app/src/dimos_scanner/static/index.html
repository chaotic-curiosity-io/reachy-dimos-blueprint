Bridge connection

LAN IP of your station (the Mac or DGX running the bridge from station/). Find it with ipconfig getifaddr en0 on macOS or hostname -I on Linux. Changing this reconnects the WS in the background.

Robot pose

Move the head and base. Sliders command absolute angles in degrees; arrow buttons nudge.

Detected objects

Live from the station pipeline — needs detection enabled and a running session. Distance is measured from the robot's camera; nearest first.
